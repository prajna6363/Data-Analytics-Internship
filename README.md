# Data Analytics Internship Projects

This repository contains the projects completed as part of my **Data Analytics Internship**.

The projects demonstrate practical experience in **Python, SQL, Machine Learning, Data Cleaning, Exploratory Data Analysis (EDA), and Power BI**.

---

## 📂 Projects

### 1. HR Analytics – Employee Attrition Prediction

This project analyzes employee data to understand attrition patterns and identify factors associated with employee turnover.

**Tools & Technologies:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Power BI

**Key Work:**
- Data cleaning and preprocessing
- Exploratory data analysis
- Attrition pattern analysis
- Logistic Regression
- Random Forest
- Model evaluation
- Feature importance analysis
- Interactive Power BI dashboard

**Key Result:**
- Overall employee attrition rate: **16.12%**
- Logistic Regression accuracy: **86.1%**

📁 Project folder: [`HR-Employee-Attrition`](./HR-Employee-Attrition)

### 2. E-Commerce Return Rate Reduction Analysis

This project analyzes e-commerce order and return data to identify return patterns and estimate return risk.

**Tools & Technologies:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- MySQL
- Power BI

**Key Work:**
- Data cleaning and validation
- Exploratory data analysis
- Return rate analysis
- SQL business analysis
- Logistic Regression
- Return risk scoring
- High-risk product analysis
- Interactive Power BI dashboard

**Key Results:**
- Total orders: **5,000**
- Returned orders: **1,450**
- Overall return rate: **29%**
- Clothing had the highest return rate at **37.43%**

📁 Project folder: [`E-Commerce-Return-Analysis`](./E-Commerce-Return-Analysis)
